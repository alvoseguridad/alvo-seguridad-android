# ALVO SEGURIDAD Android
Aplicación Android WebView que abre la página existente de ALVO SEGURIDAD. Requiere Internet. El ícono es provisional, no el logo original. La app no añade funciones de gestión de datos más allá de las que ya tenga la web.
## Crear APK
Subir el contenido de esta carpeta a la raíz del repositorio GitHub, conservando carpetas. En Actions ejecutar 'Crear APK ALVO SEGURIDAD' (o esperar al push). Descargar artifact ALVO-SEGURIDAD-APK, extraer ZIP e instalar app-debug.apk. Es un APK de prueba, no firmado para distribución pública.
